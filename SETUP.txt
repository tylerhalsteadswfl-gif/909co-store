909CO ADMIN SETUP
=================

The admin page is at:
https://909co.store/admin.html

The same owner account can be used on your iPhone and computer.

IMPORTANT: GitHub Pages cannot securely store an owner password or share cart/visitor data between devices by itself. The admin dashboard therefore uses Supabase authentication + database.

1. Create a Supabase project.
2. In Supabase, open SQL Editor and create the tables/policies needed for site_visits and cart_sessions.
3. Copy your Project URL and anon/public key.
4. Open config.js in this folder and replace the two PASTE_ values.
5. Upload config.js, index.html, admin.html, and all JPG/PNG files to the ROOT of your GitHub Pages repo.
6. On BOTH your phone and computer, open https://909co.store/admin.html and log in with the same Supabase owner account.

OWNER-ONLY BEHAVIOR
- Normal shoppers do not get the OWNER ADMIN button.
- After the owner signs in, the OWNER ADMIN button can appear at the top-left of the store on that device.
- The /admin.html page always requires the authenticated owner account.

=== VIEWS + TIME-ON-SITE UPDATE ===
Run this in Supabase SQL Editor after the original setup SQL:

alter table public.site_visits add column if not exists started_at timestamptz not null default now();
alter table public.site_visits add column if not exists duration_seconds integer not null default 0;
alter table public.site_visits add column if not exists last_seen_at timestamptz not null default now();

create policy "Anyone can update visit duration"
on public.site_visits
for update
to anon, authenticated
using (true)
with check (true);

create index if not exists site_visits_started_at_idx on public.site_visits(started_at desc);

The admin panel now shows only website views, unique visitors, and average time on site, plus a simple recent-visits table. Cart analytics are removed from the admin panel.
