909CO — GOOGLE ANALYTICS ADMIN SETUP
=====================================

This version removes Supabase completely. The public website sends traffic to Google Analytics 4, and /admin.html reads the GA4 report using Google sign-in.

WHAT THE ADMIN SHOWS
- Website views
- Average time stayed (average session duration)
- Daily views + average time for the last 28 days

Google Analytics' Data API supports the screenPageViews and averageSessionDuration metrics.

1) CREATE GOOGLE ANALYTICS
- Go to https://analytics.google.com/
- Create a GA4 property for 909CO if you do not already have one.
- Add a Web data stream for https://909co.store
- Leave Enhanced Measurement enabled.
- Copy the Measurement ID that starts with G-.

2) GET YOUR GA4 PROPERTY ID
- Google Analytics → Admin → Property Settings.
- Copy the numeric Property ID.

3) CREATE A GOOGLE OAUTH WEB CLIENT
- Go to https://console.cloud.google.com/
- Select/create a Google Cloud project.
- Enable “Google Analytics Data API”.
- Configure the OAuth consent screen if Google asks.
- Create Credentials → OAuth client ID → Web application.
- Add this Authorized JavaScript origin:
  https://909co.store
- Copy the Client ID ending in .apps.googleusercontent.com.

4) EDIT config.js
Replace the three placeholders:
window.GA_MEASUREMENT_ID = 'G-XXXXXXXXXX';
window.GA_PROPERTY_ID = '123456789';
window.GOOGLE_CLIENT_ID = 'YOUR_WEB_OAUTH_CLIENT_ID.apps.googleusercontent.com';

5) UPLOAD TO GITHUB
Upload/replace these files in the ROOT of your GitHub Pages repo:
- index.html
- admin.html
- config.js
- all the existing JPG/PNG product files

6) USE THE ADMIN
Open:
https://909co.store/admin.html

Tap SIGN IN WITH GOOGLE and choose the Google account that has access to the GA4 property. The Google Analytics Data API requires authenticated access to report data; the admin does not store a Google password or service-account secret.

IMPORTANT
- Do NOT put a Google service-account JSON key or other private secret in GitHub.
- The Google Client ID and GA Measurement ID are not passwords.
- Google says data collection can take up to about 30 minutes to begin; use the GA4 Realtime report to verify the tag.
