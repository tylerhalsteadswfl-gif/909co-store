GITHUB PAGES (IPHONE)
1. Unzip this ZIP in the Files app.
2. Upload index.html, admin.html, config.js, and the assets folder to the ROOT of your GitHub Pages repo.
3. If GitHub asks about replacing index.html, replace it.
4. Open https://909co.store and hard-refresh/reload.

ADMIN TRACKING
The admin dashboard uses Supabase for shared visitor/cart tracking. GitHub Pages alone cannot securely store shared analytics.
1. Create a Supabase project.
2. Put your Supabase URL and anon key in config.js.
3. Create the tables/policies described in the original admin setup.
4. Create your owner account in Supabase Auth.
5. Open https://909co.store/admin.html, log in with the owner account, and the dashboard will show visits and active carts.

IMPORTANT
- The admin link is hidden from the public store.
- Anyone who guesses /admin.html can see the login screen, but only an authenticated Supabase owner account can see the dashboard data.
